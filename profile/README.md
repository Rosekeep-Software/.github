# Rosekeep Software

**Dependable operations software for independent retailers.**

Rosekeep Software builds focused, self-hostable business applications for small and mid-sized
merchants — the kind of tools that run the counter, the warehouse, and the back office every day,
without enterprise pricing or lock-in.

---

### What we build

| Area | Focus |
| --- | --- |
| **Point of Sale** | Fast, reliable in-store checkout, inventory, and reporting |
| **Order Fulfillment** | Multi-channel order management, carrier rates, and label printing |

### Engineering principles

- **Correctness first** — money is stored in integer cents, every state change is auditable, and
  operations are idempotent by design.
- **Own your data** — products are built to be self-hosted on infrastructure you control.
- **Maintainable by default** — small, single-purpose modules, strong typing, and automated tests.
- **Built with operators** — features are shaped by the people who use them on the shop floor.
